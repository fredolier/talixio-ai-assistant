Use the setup code shown in the server logs: docker logs talixio-admin.

People

Each person has their own assistant, data and API keys. You manage their container, never their content.

Updates

What changes

    

      
      

    
The new version is built from the git repository, then each assistant is moved to it one by one. If one does not start, it goes back to the previous version and the update stops.

    

  


  

    
Settings

    

      
Addresses
        
        
        
        
With one address, every assistant and this admin page share one web origin: someone who can run code in their own assistant could reach the others' sessions. Choose Subdomains unless everyone on this server trusts each other.

        
Changing these restarts every assistant (a few seconds). People keep their data; their app must be opened at the new address (and installed again on phones).

Google Calendar for everyone (optional)
        
One Google OAuth client for all the assistants: each person then just presses "Connect" in their Settings. Add each address below as an authorised redirect URI of the client.

        
        
        

      

      
AI in Europe for everyone (optional)
        
One account with a European provider for all the assistants: their messages, documents and recordings stay with a provider hosted in Europe, under the GDPR. Each person can still choose otherwise in their Settings.

        
        
        
        
        
Usage is billed to this one account. Set each person's budget in their Settings.
