Set up the admin

Use the setup code shown in the server logs: docker logs talixio-admin.

Scan this with an authenticator app (Google Authenticator, Aegis, 1Password…). Signing in will always need its code.

Or type this key:

Talixio admin

People

Each person has their own assistant, data and API keys. You manage their container, never their content.

Updates

The new version is built from the git repository, then each assistant is moved to it one by one. If one does not start, it goes back to the previous version and the update stops.

Settings

Addresses

Changing these restarts every assistant (a few seconds). People keep their data; their app must be opened at the new address (and installed again on phones).
