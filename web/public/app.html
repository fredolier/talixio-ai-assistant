Library

Your documents, notes and recordings. Everything is searchable, by you and by the assistant.

    Drop files here to add them to this folder.

    Tasks

    Routines

    What the assistant does on a schedule: reminders, briefings, recurring reports. (Things to do are on the Tasks board.) Ask in chat to create them: remind me tomorrow at 9 to call the bank, every weekday at 8:00 send me a briefing.

    Morning briefing

    Your day at a glance: calendar, emails to handle, reminders, weather.

    Weekly review

    What was done, what slipped, the week ahead and 3 priorities. The full review is saved as a note.

    Watch and draftFollows topics for you (a newsletter, a market, a technology…) and writes the draft of the next issue in your library.

    Mail to handle

    Your new emails, sorted: to answer, to do, to read. Move one to another group and it learns.

    People

    From your emails, and what the assistant learns about each person.

    Background jobs

    Sub-agents the assistant starts for research and multi-step work. Each one has its own model tier and a cost cap; results come back in the chat.

    Memory

    What the assistant knows about you and how it works for you. It reads all of this before answering, and keeps it up to date as it learns; you can edit or remove anything.

    Search

    In every conversation, by words and by meaning.

    Character and values

    Learned by itself from your history together: what matters to you, how you decide, and what kind of assistant it has become. A belief grows stronger when it is confirmed over time, weaker when contradicted, and fades when nothing confirms it. It weighs the established ones in its choices. "Forget" removes a belief for good.

    Skills

    Procedures it has learned for you. It reads the matching one before doing a task, and updates them as it learns. You can edit or delete them.

    Scripts

    Python scripts it wrote for mechanical tasks it does again (converting an export, tidying a table, a recurring calculation). They run in the sandbox, which sees only its work folder. When commands need your approval, you approve a script's code once; saving it here counts as approving it.

    Conversation digest

    The assistant keeps the latest messages word for word. Older ones are summarised, then each past week and month is condensed further: details fade, what matters stays. It reads this digest before every answer; everything remains searchable.

    Memory files

    Plain text it reads before every answer. It adds to them as it learns; what you write here counts as much as what it writes.

    Settings

    Values saved in the app override /etc/talixio/talixio.env; "Reset" goes back to the file's value. Changes apply once you press Save.

      How to connect

      Windows: File Explorer → This PC → Map network drive → the address above → tick “Connect using different credentials”.

      macOS: Finder → Go → Connect to Server (⌘K) → the address above.

      iPhone, iPad: Files → ⋯ → Connect to Server → the address above.

      Android: an app that speaks WebDAV (Solid Explorer, Material Files, CX File Explorer…) → new WebDAV connection → the address above.

      The address must be in https (it is behind the server's Caddy). Large files: Windows limits downloads to 50 MB unless its WebClient setting FileSizeLimitInBytes is raised.

      Google Calendar
      1. Open console.cloud.google.com, create a project (e.g. "Talixio").
      2. Enable the Google Calendar API.
      3. OAuth consent screen: type External, your email as contact. Under Audience, press Publish app ("In production"): in "Testing" Google cuts the access after 7 days. Google will show "unverified app" when you connect: that's your own app, continue.
      4. Create an OAuth client: type Web application, authorised redirect URI:
      5. Paste its client ID and secret in the fields below, save, then press Connect.
      Outlook / Microsoft 365
      1. Open entra.microsoft.com → App registrations (sign in with your Outlook or Microsoft 365 account) and press New registration.
      2. Name "Talixio"; supported accounts: any organizational directory and personal Microsoft accounts (or only your organisation); redirect URI type Web:
      3. API permissions → Add a permission → Microsoft Graph → Delegated: Calendars.ReadWrite, offline_access, User.Read.
      4. Certificates & secrets → New client secret (24 months). Copy its Value right away.
      5. Paste the Application (client) ID and the secret in the fields below, save, then press Connect.
