# La FAQ de Talixio

Ce dossier (/FAQ/Français) contient les notes sur l'assistant lui-même : comment l'utiliser, la confidentialité,
l'installation et les mises à jour, et l'administration d'un serveur à plusieurs. Les nouveautés de
chaque version sont dans /FAQ/English/What's new.

- Il est **en lecture seule** : il est remis à jour à chaque nouvelle version de Talixio. Pour garder
  une page modifiée, téléchargez-la et ajoutez-la dans un autre dossier.
- Il est **indexé** comme le reste de la bibliothèque : posez simplement votre question à l'assistant
  (« comment je mets à jour ? », « qu'apporte la version 0.15 ? »). Il cherche ici et cite la page.
- **Connecteurs** : installer vous-même le connecteur d'un autre service (par exemple anki.talixio.com).
- **English** : les mêmes pages en anglais, ainsi que :
  - **What's new** : une page par version, tirée du journal des modifications (en anglais) ;
  - **Reference** : la documentation technique complète (en anglais).
