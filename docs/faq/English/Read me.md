# The Talixio FAQ

This folder (/FAQ/English) holds notes about the assistant itself. The same pages exist in French
in /FAQ/Français.

- It is **read-only**: it is updated with each new version of Talixio. To keep
  a changed page, download it and add it to another folder.
- It is **indexed** like the rest of the library: just ask the assistant your question
  ("how do I update?", "what's new in version 0.15?"). It searches here and cites the page.
- Subfolders:
  - **Using Talixio**: how to use the assistant day to day;
  - **Privacy**: where your data goes and how to keep it private;
  - **Installing and updating**: installing, updating, backups and troubleshooting;
  - **Administration**: running a server for several people;
  - **Connectors**: installing the connector of another service yourself (for example anki.talixio.com);
  - **What's new**: one page per version, taken from the changelog;
  - **Reference**: the full technical documentation (README and Docker README).
