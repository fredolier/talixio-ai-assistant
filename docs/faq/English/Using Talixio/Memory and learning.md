# Memory and learning

- **Memory page**: one section at a time from the side menu (chips on a phone), each with a word on what it
  holds: *Character and values*, *Skills*, *Scripts*, *Conversation digest* and *Memory files*: `USER.md`
  (about you), `MEMORY.md` (notes), `SOUL.md` (personality), `HEARTBEAT.md` (checklist), all editable. The box
  at the top searches the whole history; Esc or emptying it brings the sections back.
- **Gradual forgetting**: the latest messages are sent word for word, older ones are summarised
  by period, then by week and by month. Nothing is deleted: everything stays searchable.
- **Skills**: the procedures learned for you, in Markdown; the assistant tells you
  when it learns one. View, edit or delete them on the Memory page.
- **Scripts** (with the sandbox): when it does the same mechanical work again (converting an export,
  tidying a table), it saves the Python code as a script and reuses it. When commands need your approval,
  you approve a script's code once. View, edit or delete them on the Memory page. To add your own: **New script**
  or **Upload a .py** there, or open a `.py` in the library and choose **Use as a script** (under More on a phone):
  a confirmation in the viewer says where it went, with **Show the script**.
- **Character and values**: what matters to you, how you work, what it should do
  better; each belief with its evidence, *Why?* and *Forget*. Never about health, religion,
  politics, sexuality or origins.
