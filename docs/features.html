talixio-ai-assistant · v0.1

A personal AI that lives on your server and answers on Telegram.

Install one Debian package. It runs as a service around the clock, remembers what you tell it, uses Claude or OpenAI as its brain, and can message you first on a schedule.

What it does today

Works now

Chat from your phone

Message your own Telegram bot. Only the chat ids you list can talk to it.

Works now

Remembers you

Conversation history and long-term facts are stored in SQLite on your machine. The model saves a fact itself when you say something worth keeping.

Works now

Messages you first

Daily jobs such as a morning briefing run at a time you set (UTC) and arrive in your chat.

Works now

Your choice of model

Claude, OpenAI, or any OpenAI-compatible server such as Ollama running on your own hardware.

Works now

Reads web pages

The fetch_url tool lets it open a link you send and summarize it.

Works now

Stays up

systemd restarts it after a crash or reboot. Logs go to journalctl -u talixio.

Needs Ollama or similar

Fully private mode

Point OPENAI_BASE_URL at a local model server. Chats and memory then never leave your machine, apart from Telegram itself.

OPENAI_BASE_URL=http://localhost:11434/v1
TALIXIO_PROVIDER=openai
TALIXIO_MODEL=llama3.1
Not built yet

Run commands, edit files, code

No shell or file tools exist yet. A Claude Code backend for agentic work is the planned next step, with confirmation before anything destructive.

Not built yet

Email, calendar, voice, other chat apps

Only Telegram is connected. Discord, WhatsApp, email and voice are not implemented.

How it compares

OptionWhere it runsStrengthTrade-off
TalixioYour serverTiny, readable PHP. Installs with apt. You own the data and choose the model.v0.1: one channel, four tools, no agentic coding or integrations yet.
Hosted assistants (ChatGPT, Claude apps, custom GPTs)Vendor cloudPolished, many features, no setup.Not on your server, no scheduled messages from you, data lives with the vendor.
Self-hosted agent frameworks (Hermes Agent and similar)Your serverBroader: more channels, skills, tool ecosystems, sandboxed execution.Larger and more to configure and secure. Check each project for current features.
Companion / persona bots (Muse and similar)Usually vendor cloudPersonality and roleplay tuned for conversation.Mostly closed, little control over data or model. Talixio can approximate a persona with TALIXIO_PERSONA but is not tuned for it.

The rows for other products are general categories, not a feature-by-feature audit. I have not tested them against Talixio. The honest summary: choose Talixio if you want a small assistant you fully control and can extend in PHP. Choose a larger framework if you need many integrations or autonomous coding today.
